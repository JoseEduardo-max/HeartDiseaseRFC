Classificação com Random Forest

Hoje vou apresentar um modelo de Machine Learning aplicado à classificação de doenças cardíacas. O objetivo é prever se um paciente tem ou não a doença com base em dados clínicos.

🎯 Objetivo

  • Classificar pacientes (doença ou não)
  • Comparar diferentes modelos
  • Analisar impacto dos parâmetros
O foco do trabalho é classificação binária. Também buscamos entender como os parâmetros influenciam o modelo. E comparar o Random Forest com uma Decision Tree.

📊 Base de Dados

  • Dados clínicos reais
  • Ex: idade, colesterol, pressão
  • Target: presença de doença
  • Problema de classificação supervisionada
O dataset contém informações médicas de pacientes. As features representam características clínicas. O target indica se há doença cardíaca. É um problema supervisionado, pois temos a resposta correta.

🌳 Modelo 1 (Random Forest - Padrão)

  • Sem ajuste de parâmetros
  • Base para comparação
  • Acurácia: XX%
Aqui utilizamos o Random Forest com parâmetros padrão. Esse modelo serve como baseline. Ou seja, ele é nossa referência inicial. Depois vamos comparar com o modelo ajustado.

🌲 Modelo 2 (Random Forest Ajustado)

  • n_estimators = 200 (mais árvores)
  • max_depth = 10 (controle de complexidade)
  • Menor overfitting
  • Acurácia: XX%
Aqui ajustamos os parâmetros. Aumentamos o número de árvores para melhorar a precisão. Limitamos a profundidade para evitar overfitting. Isso geralmente melhora a generalização do modelo.

📉 Matriz de Confusão

  • Mostra acertos e erros
  • Verdadeiro positivo / negativo
  • Falsos positivos e negativos
A matriz de confusão mostra como o modelo performa. Verdadeiros positivos são acertos de doença. Verdadeiros negativos são acertos sem doença. Já os erros são falsos positivos e falsos negativos. Isso é importante porque na saúde erros podem ser críticos.

📊 Importância das Features

  • Identifica variáveis mais relevantes
  • Ajuda na interpretação do modelo
  • Ex: colesterol, idade, pressão
O Random Forest permite analisar a importância das variáveis. Isso mostra quais fatores mais influenciam a decisão. Em contexto médico, isso é extremamente útil.

⚔️ Comparação de Modelos

  • Random Forest vs Decision Tree
  • RFC teve melhor desempenho
  • Mais robusto e estável
Aqui comparamos os modelos. O Random Forest teve melhor desempenho. Isso acontece porque ele combina várias árvores. Já a Decision Tree é mais simples e tende a errar mais.

🧠 Análise dos Resultados

  • Mais árvores → melhor precisão
  • Controle de profundidade → evita overfitting
  • RFC generaliza melhor
A análise mostra que aumentar árvores melhora o desempenho. Controlar a profundidade evita que o modelo decore os dados. O Random Forest conseguiu generalizar melhor que a árvore única.

🎤 Conclusão

  • Random Forest foi o melhor modelo
  • Maior precisão e estabilidade
  • Aplicável em problemas reais
Concluindo, o Random Forest apresentou melhor desempenho. Ele é mais robusto e confiável. E pode ser aplicado em problemas reais, como diagnóstico médico.
